# Expert Club — Codex Handoff Pack

Este pacote contém tudo para o Codex implementar o polish visual do Expert Club com fidelidade às telas geradas.

## Arquivos

- `CODEX_IMPLEMENTATION_PROMPT.md` — prompt final para colar no Codex.
- `design-tokens.json` — tokens de design para usar na implementação.
- `assets/` — imagens de referência obrigatórias.
- `prototype/index.html` — protótipo HTML/CSS estático com as telas como referência técnica.

## Como usar

1. Suba este ZIP no Codex junto com o projeto.
2. Cole o conteúdo de `CODEX_IMPLEMENTATION_PROMPT.md` como instrução principal.
3. Peça para ele abrir as imagens em `assets/` e usar o protótipo como guia estrutural.
4. Exija browser visual QA e comparação tela a tela.

## Regra principal

Não é para reinventar. É para implementar pixel-close ao visual das imagens.
