# Controle do Lançamento Fundador

Use este controle para comparar as variações de hero por influenciadora sem olhar só clique.

## Links

Modelo:

```txt
https://seudominio.com/?ref=SEUCODIGO&hero=B&utm_source=affiliate&utm_campaign=stories
```

Exemplos:

```txt
https://seudominio.com/?ref=MARI384&hero=B&utm_source=affiliate&utm_campaign=stories
https://seudominio.com/?ref=ANA123&hero=A&utm_source=affiliate&utm_campaign=stories
```

## Funil para decidir vencedora

Não decida só por curtida, resposta no story ou clique.

Olhe o funil completo:

```txt
visitas na landing
-> cliques no CTA
-> checkoutSessions criadas
-> pagamentos aprovados
-> assinaturas ativas
-> comissão gerada
```

A headline vencedora não é necessariamente a que recebe mais clique. É a que gera mais pagamento aprovado e assinatura ativa.

## Mensagem para afiliada

```txt
Perfeito, seu link de divulgação ficou assim:

https://seudominio.com/?ref=SEUCODIGO&hero=B&utm_source=affiliate&utm_campaign=stories

Toda assinatura feita por esse link fica vinculada ao seu código. A comissão é de 20% recorrente enquanto o aluno indicado continuar ativo e pagando.

Pode usar nos stories, bio ou legenda. O ideal é falar de forma simples: o Expert Club é um app com treino, dieta, check-ins, controle de água, desafios e grupo no WhatsApp para quem quer parar de se perder no treino e na dieta.
```

- Hero A pode gerar compra mais qualificada, porque explica melhor o produto.
